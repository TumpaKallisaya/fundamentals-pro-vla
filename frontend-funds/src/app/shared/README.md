# Shared

Piezas **reutilizables** entre features, sin lógica de negocio específica.

Aquí van:

- `components/` — componentes de UI genéricos (botones, tablas, tarjetas, badges).
- `directives/` — directivas reutilizables.
- `pipes/` — pipes de formato.
- `models/` — modelos/tipos compartidos.

No debe depender de ninguna feature.
